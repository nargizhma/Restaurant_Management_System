# 🍽️ Restaurant Management System (EF Core)

## 📌 Overview
This project is a console-based backend system built using **C# and Entity Framework Core (EF Core)**.  
It manages restaurants, tables, menu items, and customer orders while dynamically tracking sales and statistics.

---

## 🚀 Features
- Full CRUD operations for:
  - Restaurants
  - Tables
  - Menu items
  - Orders
- Order processing system with automatic updates:
  - Total revenue
  - Order count
  - Item sales statistics
- Data validation (unique constraints, relationships)
- Real-time statistics and reporting

---

## 🧠 Technical Implementation
- Developed using **C# (.NET Console Application)**
- Database operations handled via **Entity Framework Core**
- Designed relational models and entity relationships
- Implemented:
  - **N-tier architecture**
  - **Repository pattern**
  - **Service layer**
- Followed **clean code principles**

---

## 🗄️ Technologies Used
- C#
- .NET
- Entity Framework Core (EF Core)
- SQL Server

---

## 📊 Example Functionalities
- View restaurant performance statistics
- Track most sold menu items
- Manage customer orders and tables
